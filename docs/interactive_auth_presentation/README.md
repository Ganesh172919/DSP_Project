# Interactive Facial Authentication Presentation

This folder contains a static interactive presentation for the facial authentication project.

Files:

- `index.html`: presentation structure and slide regions.
- `styles.css`: visual design, animations, layout, and responsive behavior.
- `app.js`: slide state, keyboard navigation, model data, simulator, and animated pipeline behavior.

Open `index.html` directly in a browser.

Recommended controls:

- `Right Arrow` or `Space`: next slide.
- `Left Arrow`: previous slide.
- Number keys `1` to `9`: jump to a slide.
- `R`: replay the current slide animation.

The deck covers:

- entire system flow
- model-by-model explanation
- registration pipeline
- authentication decision gates
- liveness and deepfake analysis
- VLM hybrid reasoning
- security and storage
- threat scenarios
- presentation-ready speaker notes
